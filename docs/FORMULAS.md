# ФОРМУЛЫ РАСЧЁТА СТОИМОСТИ ЖИЗНИ — ReloCalc

*Версия: июль 2026 (актуализировано — см. ARCHITECTURE_LIFESTYLE_FILTER.md)*

Этот документ описывает формулы, реализованные в `lib/calc/formulas.ts`. Служит опорой для понимания логики без необходимости каждый раз перечитывать код целиком.

---

## Стили жизни

```ts
export type LifeStyle = 'economy' | 'comfort' | 'comfort_plus'

```

- `economy` — Эконом
- `comfort` — Базовый комфорт
- `comfort_plus` — Комфорт+

*Примечание: в перспективе к системным пресетам добавятся кастомные пользовательские стили (см. ARCHITECTURE_LIFESTYLE_FILTER.md, раздел 3) — они будут использовать ту же расчётную логику через набор оверрайдов поверх системных коэффициентов.*

## Коэффициенты продуктов (W_food)


| Категория            | Коэффициент                                                             |
| -------------------- | ----------------------------------------------------------------------- |
| Первый взрослый      | 1.0                                                                     |
| Каждый доп. взрослый | +0.7                                                                    |
| Ребёнок              | +0.4                                                                    |
| Младенец             | не добавляет коэффициент — считается отдельно через `baby_supplies_usd` |


```ts
function calcGroceriesMultiplier(adults, children): number {
  if (adults === 0) return 0
  return 1.0 + (adults - 1) * 0.7 + children * 0.4
}

```

## 3. Коммунальные услуги

**Обновлено:** масштабируется по стилю жизни аналогично аренде (раздел 2). Прежняя версия ("фиксировано, всегда `utilities_usd_min`") больше не действует.


| Стиль    | Формула                                       |
| -------- | --------------------------------------------- |
| Эконом   | `utilities_usd_min`                           |
| Базовый  | `(utilities_usd_min + utilities_usd_max) / 2` |
| Комфорт+ | `utilities_usd_max`                           |


Поля в БД: `utilities_usd_min`, `utilities_usd_max` — по выбранному типу жилья и количеству спален.

**Требуется в коде:** добавить `utilities_usd_max` в `CalcInput`, завести `calcUtilities()` по аналогии с `calcRent()`, заменить `const utilities = input.utilities_usd_min` на вызов новой функции.

## 5. Общественный транспорт

**Шаг 1.** Стоимость проездного на 1 взрослого:

- если `transport_monthly_pass_usd > 0` → берём его
- иначе → `transport_single_ticket_usd × 44` (22 рабочих дня × 2 поездки)

**Шаг 2.** Итого на семью:

```
pass_checked × pass_adult × (adults + children × 0.5)

```

`pass_checked` по стилю жизни:


| Стиль    | pass_checked                    |
| -------- | ------------------------------- |
| Эконом   | 1 (включён)                     |
| Базовый  | 1 (включён)                     |
| Комфорт+ | 0 (выключён — используют такси) |

## 12. Детский сад

**Правило по стилю жизни (подтверждено намеренным):**

```ts
if (lifestyle === 'economy') return 0

```

В Экономе сад по умолчанию не оплачивается — расчёт исходит из того, что в этом стиле жизни ребёнок не ходит в частный сад, даже если в стране образование платное. Если пользователь явно включает сад в кастомизации (модал "Задать свой стиль" — см. ARCHITECTURE_LIFESTYLE_FILTER.md, раздел 3), стоимость добавляется поверх эконома.

Для остальных стилей:

- если `kindergarten_is_free = true` → 0
- иначе → `kindergarten_usd × kids_in_kindergarten`

`kids_in_kindergarten` — счётчик из фильтра пользователя.

---

## 13. Школа

Та же логика, что и для сада (раздел 12):

```ts
if (lifestyle === 'economy') return 0

```

В Экономе школа по умолчанию не оплачивается (частная недоступна по дефолту). Явное включение в кастомизации добавляет стоимость.

Для остальных стилей:

- если `school_is_free = true` → 0
- иначе → `school_usd × kids_in_school`

`kids_in_school` — счётчик из фильтра пользователя.

## Итоговый расчёт

```
Бюджет = Продукты + Аренда + Коммуналка + Интернет/Связь
       + Транспорт + Такси + Кафе + Бьюти + Фитнес
       + Коворкинг + Страховка + Сад + Школа + Кружки + Младенец

```

Реализовано в `calcTotal(input: CalcInput)`, возвращает разбивку по каждой статье + `total`.
